# EMT919

Public website for EMT919 — Emergency Mobile Translation.

## Positioning

EMT919 helps public-safety personnel communicate during the first critical minute of a call. The site focuses on scene control, officer safety, direct communication, and simple agency procurement.

## Local preview

Open `index.html` in a browser or serve this directory with any static web server.

## Netlify

The production site is deployed through Netlify and uses the custom domain:

- https://emt.city919.com

Netlify configuration is stored in `netlify.toml`.
