# EMT919 Zoom backgrounds

These backgrounds are prepared at 1920 x 1080 pixels in the recommended 16:9 format.

## Included

- `EMT919_Zoom_Executive_Office_1920x1080.png` - polished navy and walnut executive setting
- `EMT919_Zoom_Operations_Center_1920x1080.png` - public-safety communications environment
- `EMT919_Zoom_Civic_Workspace_1920x1080.png` - bright, welcoming collaboration office

## Install in Zoom

1. Open Zoom Settings.
2. Select **Background & effects**.
3. Choose the plus button and select **Add image**.
4. Select one of the three PNG files.

The compositions leave the middle of the frame open for the speaker. If the logo appears reversed only in your own self-view, turn off **Mirror my video**; other participants generally see the correct orientation.
