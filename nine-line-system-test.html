    Results and privacy limits

    Six feet is the owner’s target for this setup, not a validated universal standard. Results are self-reported, not verified native 9/Line compatibility scores, and apply only to the distances and conditions tested. Browser capture can differ from 9/Line’s native audio pipeline. This tests the microphone; speaker and earpiece tests are separate.

    Recordings stay in memory and disappear on reload or close. No audio uploads, downloads, persistent history, speech recognition or analytics. Optional submissions contain no names, audio or free-text notes. Other visitors cannot read them; anonymous senders cannot retrieve or delete individual submissions afterward. Hosting infrastructure processes ordinary connection information.

    Microphone access needs HTTPS and browser support. Open this page directly if an embedded preview blocks it.
